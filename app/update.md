# Changelog (translated)

## 2.5.7 beta
- Still have not tracked down the black border issue. If you hit it, please send screenshots of the Mi-Freeform settings page and the problematic app.
- Fixed crash when locking the screen while an app is already running in freeform (q220902.1)
- Fixed (needs testing) some portrait apps opening in landscape (q220902.2)
- Fixed (needs testing) sidebar appearing in the middle of the screen (q220902.3)
- Added ability to open the sidebar via an activity

## 2.5.8 beta
Special note: Mi-Freeform is built for near-stock Android. Running it on heavily customized ROMs may produce unexpected problems.
- Optimized hang-up position of freeform windows in landscape (q220903.1)
- Removed the compatibility mode option
- Re-enabled Xposed prevention of freeform windows jumping to full screen on Android 10
- Fixed freeform rotation not working on Android 10 (q220903.2)

## 2.5.9 beta
- Fixed (attempt) abnormal recorded freeform window size (q220904.1)
- Allowed a larger range for freeform scaling
- Fixed crash caused by negative DPI after DPI adjustment (q220904.2)
